# Website admin — guide for Amma (iPad)

This is how to change anything on the Geethanjali Digital World website from the iPad.

---

## Opening the admin

1. Open **Safari** and go to the admin address Bhanu gave you (it ends in **/admin/**).
   *Tip:* Share button → **Add to Home Screen**. Next time, just tap the **Site Admin** icon.
2. Type the **passcode** → **Unlock**.

## The screen

- **Left menu** (tap **☰** if you don't see it): all the parts of the website.
- **Top right:**
  - **👁 Preview** — shows the website with your changes before anyone else sees them.
  - **⬇** — Download (a backup; you normally don't need it).
  - **⬆ Publish** — puts your changes on the real website.
- **Status:** *✓ All changes published* or *● Unpublished changes*.

**Every text has two boxes:** **తెలుగు** on the left and **English** on the right. If you leave one empty, visitors see the other language.

Your changes are saved on the iPad automatically. If Safari closes, nothing is lost: next time the admin asks *"Continue editing?"*

## Everyday tasks

### ➕ Add a new portfolio project
1. **Dashboard → + Add project** (or menu → **Portfolio projects → + Add project**).
2. Fill in:
   - **Category** (Logos / Posters / Websites)
   - **Title** — Telugu and English
   - **Client**, **Date** (e.g. `2026-10`)
   - **One-line summary** and **Description**
3. **Grid image** → **Choose photo** → pick it from Photos. The admin makes it the right size.
4. Under **Images**, add one or more photos (**+ Add**, then **Choose photo**).
5. Switch on **Show on home page** if it should appear on the home page too.
6. **Preview**, then **Publish**.

### 🖼 Change a photo
Open the item → **Change photo** → pick the new one → **Publish**.

### 🙈 Hide or delete something
- **Hide** (keeps it for later): switch off **Show on website**.
- **Delete:** the **✕** button on the right → **Delete**.
- **Order:** the **↑ ↓** buttons.

### 🎉 Turn on a festival offer
1. Menu → **Offers**. Tap the offer, or **+ Add offer** for a new one.
2. Write the title, price line and items in both languages. Add the poster with **Choose photo**.
3. Set the **Start date** and **End date**.
4. Switch on **Offer switched on**.
5. **Publish.** The offer shows in the Contact section and hides itself after the end date.

### ✍️ Write a blog article
1. Menu → **Blog articles → + Add article**.
2. Title, short summary and **Article text** in both languages.
3. In the article text:
   - Leave an **empty line** between paragraphs.
   - `## ` at the start of a line makes a **heading**.
   - `- ` at the start of a line makes a **bullet point**.
   - `**words**` makes them **bold**.
4. **Preview → Publish.**

### 📞 Change the phone number, WhatsApp or email
Menu → **Contact details & social**. The change shows everywhere on the site automatically.

### 🧩 Move or hide a home-page section
Menu → **Section order & search**. Use the switch to show or hide a section, and **↑ ↓** to move it.

---

## Publishing

1. Tap **⬆ Publish**.
2. Wait for **"Published! 🎉"**.
3. The real website updates in **1–2 minutes**. If you still see the old version, pull down to refresh.

## If you see a message

| Message | What to do |
|---|---|
| *Publishing is not set up* | Ask Bhanu. The GitHub key needs to be added to this iPad. |
| *GitHub did not accept the key* | The key has expired. Ask Bhanu for a new one. Your changes are safe on the iPad. |
| *The website was changed somewhere else* | Someone (maybe Bhanu) changed the site too. Tap **Cancel** and call Bhanu, or **Publish my version** to replace theirs. |
| *Could not reach GitHub* | Check the Wi-Fi, then tap Publish again. |
| *That passcode is not right* | Try again carefully. After 5 wrong tries, wait 30 seconds. |

When you're done, menu → **🔒 Lock admin**.
